# Bank Marketing Campaign Analysis

## 📊 Project Overview
This project focuses on analyzing bank marketing data to identify key customer segments and factors influencing the success of term deposit subscriptions. The goal was to process raw data and build an interactive reporting system for business decision-making.

## 🛠️ Tech Stack
* **Python (Pandas, NumPy)** – Data cleaning, feature engineering, and preprocessing.
* **Jupyter Notebook** – Exploratory Data Analysis (EDA).
* **Looker Studio** – Interactive visualization and dashboarding.

## 📁 Project Structure
* `bank_analysis.ipynb` – Main Python script for data transformation.
* `data/` – Folder containing the raw `bank.csv` and processed datasets.
* `dashboard/` – Screenshots of the final report.
* `requirements.txt` – List of necessary Python libraries.
* `.gitignore` – Configuration to exclude system and environment files.
